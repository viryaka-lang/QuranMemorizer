# مصحف ورش

تطبيق ويب تقدّمي (PWA) قابل للتثبيت لمصحف التجويد برواية ورش عن نافع كاملاً (604 صفحات)، ويمكن أن يعمل دون اتصال بالإنترنت.

## الاستضافة
يجب نشر التطبيق عبر HTTPS حتى يمكن تثبيته. باستخدام GitHub Pages: الإعدادات ← Pages ← النشر من فرع، المجلد الجذر.

## التثبيت على أندرويد
افتح رابط الموقع في متصفح Chrome ← القائمة (⋮) ← **تثبيت التطبيق** أو **الإضافة إلى الشاشة الرئيسية**.

## المزايا
- صور الصفحات ملفات مستقلة في مجلد `pages/` (`001.webp` إلى `604.webp`، نحو 105 ميغابايت).
- القراءة دون اتصال اختيارية (متوقفة افتراضياً): عند تفعيلها من الإعدادات تُحفظ جميع الصفحات على الجهاز (نحو 105 ميغابايت)، وعند إيقافها تُحذف.
- أوضاع القراءة: نهاري، دافئ، ليلي، أسود (خلفية سوداء تماماً لشاشات OLED)، مع شريط للتحكم في السطوع (المفتاح `N` يبدّل الوضع).
- موضعان للقراءة يحفظ كلٌّ منهما صفحته: «الورد اليومي» و«التعلّم»، والتبديل بينهما بزر بجانب العلامة (المفتاح `T`).
- تقليب الصفحات بالسحب (تتبع الصفحة الإصبع) أو بالضغط على الجانبين، مع خيار لحركة التقليب (انزلاق، تلاشٍ، بدون) وخيار للاهتزاز عند كل صفحة.
- إمكانية إخفاء شريط التنقل السفلي من الإعدادات، مع بقاء التقليب بالسحب أو بالضغط على الجانبين.
- حجم الصفحة: «ملاءمة الصفحة» بأبعادها الأصلية، أو «ملء الشاشة» لتمديد الصفحة على الشاشة كلها (المفتاح `Z`).
- رقم الإصدار يظهر في الإعدادات (القائمة ← الإعدادات ← التطبيق ← الإصدار)، ويزيد واحداً مع كل تعديل (commit)، ويظهر تنبيه للتحديث عند نشر إصدار جديد.
- زر للتثبيت، واختصارات على أيقونة التطبيق (سورة الفاتحة، سورة البقرة، العلامات)، وإبقاء الشاشة مضاءة، وتثبيت اتجاه الشاشة.

## بيانات الصفحات
الملف `data.js` يحدد أول آية في كل صفحة، وعدد آيات كل سورة، وبداية كل حزب. مواضع الآيات مأخوذة من مكتبة
[quran-meta](https://github.com/quran-center/quran-meta) (رخصة MIT) ومُراجَعة على صور الصفحات، وبدايات الأحزاب مأخوذة من
العناوين المطبوعة «حزب» وعلامات ۞ في الصفحات (أربعة منها تختلف عن quran-meta: الصفحات 132 و142 و252 و382).

## رقم الإصدار
الرقم محفوظ في `version.js`، ويزيده خطّاف git تلقائياً مع كل commit. فعّله مرة واحدة في كل نسخة من المستودع:

```
git config core.hooksPath .githooks
```
